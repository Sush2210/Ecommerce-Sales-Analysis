# E-Commerce Sales Analysis using SQL


## Project Overview
This project uses SQL to analyze e-commerce orders, customer spending, and product sales.

## Tools Used
- MySQL
- SQL

## Analysis Performed
- Customer and order analysis
- Product-wise sales
- Customer-wise revenue
- Total revenue calculation
- Monthly sales analysis

## Key Results
- Total Orders: 5
- Total Products Sold: 8 units
- Total Revenue: ₹93,700
- Highest Revenue Product: Laptop
- Laptop Revenue: ₹90,000

## Conclusion
This project demonstrates basic SQL skills, including SELECT queries, JOINs, aggregate functions, GROUP BY, and ORDER BY.
